# Utilidades y Scripts de TestyPal

Este repositorio contiene herramientas y scripts auxiliares de código abierto que utilizamos en el desarrollo diario de [TestyPal](https://testypal.tecnoypal.com).

## 🚀 ¿Qué es TestyPal?
Somos la plataforma definitiva para opositores. Diseñada para que aceleres tu preparación y domines tus [oposiciones](https://testypal.tecnoypal.com/oposiciones) mediante simulacros interactivos. Practica sin límites con miles de preguntas tipo test online.

## 🛠️ Contenido de este repositorio
* `ping-indexnow.js`: Un script en Node.js que usamos para notificar automáticamente a buscadores como Bing cuando actualizamos nuestro catálogo de convocatorias o publicamos nuevos artículos en el blog.

Si te estás preparando para una plaza pública y quieres conseguir tu plaza, ¡visita nuestra web principal!
